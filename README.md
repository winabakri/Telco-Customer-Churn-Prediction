# Telco Customer Churn Prediction

## Project Overview
A data mining project focused on analysing customer churn patterns and predicting customers at risk of leaving a telecommunications service provider.

## Objectives
- Analyse customer behaviour and churn patterns.
- Develop and compare predictive classification models.
- Identify high-risk customer segments to support customer retention strategies.

## Tools & Techniques
- SAS Enterprise Miner
- Logistic Regression
- Decision Tree
- Neural Network
- Predictive Modelling and Model Evaluation

## Dataset
Analysed approximately 20,000 customer records.

## Methodology
1. Data preparation and exploration.
2. Predictive model development.
3. Model performance comparison.
4. Identification of high-risk customers.
